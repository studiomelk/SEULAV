# Central de Ajuda SeuLav

MVP inicial da central de atendimento da unidade SeuLav Bom Retiro.

Unidade: R. Newton Prado, 767 — Bom Retiro, São Paulo — SP — 01127-000.

A rota pública é `/ajuda`.

A primeira versão é determinística e não usa API de IA. O formulário de dúvidas usa armazenamento local apenas para prototipagem. A próxima etapa deve trocar isso por uma API segura + banco, autenticação administrativa e notificações.
